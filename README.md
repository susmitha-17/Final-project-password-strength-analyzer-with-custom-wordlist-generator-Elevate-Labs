# Final-project-password-strength-analyzer-with-custom-wordlist-generator-Elevate-Labs
A Python-based cybersecurity tool that analyzes password strength using zxcvbn and generates custom wordlists based on user inputs (name, DOB, pet name, keywords, etc.). This project is a Python-based GUI application built using Tkinter that evaluates the strength of user-entered passwords and generates a customized wordlist based on user details. It is designed as part of the Elevate Labs Internship Project to enhance cybersecurity awareness and help users create strong, secure passwords.

**Features:**     
Real-time password strength checking Strength evaluation based on:    
Length,    
Use of uppercase & lowercase letters,    
Numbers,    
Special characters.    
Custom Wordlist Generator: Uses user inputs (name, date of birth, pet name, etc.) Creates targeted wordlists for testing password strength User-friendly Tkinter GUI.


**Tools & Technologies Used:**     
Python Tkinter for GUI development Regex for password validation File handling for saving generated wordlists.


**How It Works:**     
User enters a password,    
The application analyzes:     
Character combinations,     
Length,     
Complexity level,      
Displays a labeled strength level,      
Optionally, user enters personal details to create a custom wordlist,         
Saves the wordlist as a .txt file for further use in password auditing,     


**Objective:**    
To help users understand password security and provide a tool that improves password strength through automated analysis and wordlist-based testing.


**Future Enhancements:**   
Add breach-checking using public APIs.   
Export reports in PDF format.


**Conclusion:**
This project demonstrates foundational cybersecurity skills by combining password analysis and wordlist generation in a simple Tkinter GUI. It helps users create safer passwords and understand common password weaknesses.
